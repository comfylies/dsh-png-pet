# 桌宠物理化弹跳卡顿：修复与安装说明

> 记录 2026-09-03 对"趣味功能 → 角色物理化"（拖拽抛出后弹跳）偶发掉帧问题的定位、修复与安装过程。涉及 Helper（C#/WPF）侧改动；协议与 TypeScript 侧无任何变更。

## 现象

- 鼠标**拖拽**桌宠：流畅。
- 拖拽**松手抛出**后弹跳/大幅移动：帧率明显变低、偶发一顿一顿（本机为 120Hz 显示器）。

## 排查结论（测量数据）

Helper 内置逐帧诊断（每段飞行一条日志，见下），在 120Hz 屏上 2×2 实测：

| 飞行驱动方式 | 平均事件间隔 | 最坏间隔 | >17ms 慢帧占比 |
| --- | --- | --- | --- |
| 暂停动画 + WPF 渲染事件驱动（旧默认） | ~13ms | ~47ms | 41–65% |
| 保持动画 + WPF 渲染事件驱动 | ~7ms | ~38ms | 17% |
| 保持动画 + 1ms 定时器分辨率 | ~6.7ms | ~30ms | 8% |
| **按实测刷新率节拍的定时器驱动（pacer）** | **~7.7ms** | **~12–13ms** | **0%** |

结论：

1. 单次窗口移动（SetWindowPos）与物理计算都很便宜（<1ms），**不是瓶颈**。
2. 根因是 WPF `CompositionTarget.Rendering` 事件对透明窗口的送达呈"亚毫秒连发 + 30–47ms 空洞"的突发模式，等于 120Hz 屏上偶发漏掉 2–4 帧；事件驱动的移动还会自激窗口消息拥塞（偶发 10ms+ 移动尖峰）。
3. 修复：飞行期间不再等待 WPF 渲染事件，改由**高精度定时器按实测显示器刷新率（GetDeviceCaps 探测）每帧恰好发起一次窗口移动**（pacer），并同时请求 1ms Windows 定时器分辨率。pacer 实测 ≈119.8 次移动/秒、0% 慢帧、最坏间隔 12–13ms、移动耗时 <2.4ms——与拖拽同为 OS 级搬窗，互手感一致。

## 现在的默认行为

- 物理飞行窗口移动：**pacer**（按显示器实测刷新率 1 帧 1 次；探测失败回退 60Hz 步进）。
- 飞行期间角色动画：**保持播放**（hot，画面更活泼且不影响节奏）。
- 拖拽期间：仍按原逻辑暂停动画、由 OS 原生移动（不重绘窗口表面）。

## 环境变量开关（诊断/回退用，均可不设）

| 变量 | 值 | 效果 |
| --- | --- | --- |
| `DSH_PNG_PET_SELFTEST` | `1` | 启动后自动按 4 段矩阵坠落（hot+burst / hot+timer / hot+pacer / paused+pacer），每段写一行日志 |
| `DSH_PNG_PET_PHYSICS_PACER` | `0` | 关闭 pacer，退回 WPF 渲染事件驱动（默认开启） |
| `DSH_PNG_PET_PHYSICS_KEEP_ANIMATION` | `0` | 飞行时暂停角色动画（默认保持播放） |
| `DSH_PNG_PET_PHYSICS_PACED` | `1` | 固定 1/60s 步进推进（诊断用） |
| `DSH_PNG_PET_PHYSICS_TIMER_RES` | `1` | 非 pacer 模式也启用 1ms 定时器分辨率 |

## 诊断日志

路径：`%LocalAppData%\DshPngPet\pet-helper-physics.log`（纯数字，无任何会话内容；超过 1MB 自动截断）。每段物理飞行一行：

```
physics flight mode=hot+pacer refresh=120.0 ticks=363 intervalMs=2.95/7.77/12.03 slow=0 moveMs=0.569/2.360 durationMs=3029
```

字段：`mode=动画状态(paused/hot)+驱动(burst/timer/paced/pacer)`、`refresh=` 实测刷新率、`ticks` 移动次数、`intervalMs=最小/平均/最大`（真实两次移动间隔）、`slow` 超过 17ms 的次数、`moveMs=平均/最大`（单次 SetWindowPos 耗时）、`durationMs` 飞行时长。

## 本次安装（2026-09-03）

1. 编译并运行 C# 单测：`dotnet test pet-helper.Tests\PetHelper.Tests.csproj`（309 通过）。
2. 构建自包含 Helper：`npm run build:helper`（输出 `runtime/bin/win32-x64/pet-helper.exe`）。
3. 打包：`npm run package:release`（产物 `dist\packages\dsh-png-pet-0.2.3.tgz`）。
4. 覆盖安装到当前 profile（`C:\dsh-packages\dsh-png-pet-current.tgz` → `dsh plugin --profile web remove/add`）。
5. 重启 DSH Harness 后生效（已运行的 Harness 不会热加载新包）。
