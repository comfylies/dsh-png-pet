# 桌宠角色三视图设计

## 目标

根据 `images/` 中现有的蓝发鲨鱼女仆角色插画，生成一张可作为后续 PNG 动作帧统一参考的三视图草案。本次只生成和评审三视图，不替换现有动画帧或修改动画清单。

## 交付物

- 单张横向三视图设定稿。
- 同一画布从左至右依次为正面、角色右侧面和背面。
- 三个视图均为完整全身、中立自然站姿、等比例，角色不裁切。
- 真正透明背景；不含文字、对白框、贴纸描边、地面、道具或其他角色。

## 角色不变量

- Q 版日系插画比例，圆润头身比和干净清晰的深色描线。
- 深蓝至青蓝渐变的长卷发，头顶单根呆毛，白色荷叶边发箍。
- 深蓝鲨鱼耳鳍，右侧蓝色蝴蝶结，以及深蓝鲨鱼尾；尾巴从臀后（腰线下方的身体后中线）自然伸出，不能连接在身体侧面。
- 深蓝与白色女仆裙、白围裙、深色蝴蝶结和白袜深色鞋。
- 围裙保留简洁蓝色鲸鱼图案；布料褶皱、发梢和尾鳍在三视图之间保持一致。

## 生成与验收

使用现有三张 PNG/JPG 作为角色和风格参考。首次输出用于人工校对角色一致性，而不是直接投入帧播放。验收时检查：三个方向齐全、比例统一、透明 alpha 保留、所有关键设定在背面和侧面均有合理延续，且没有出现文字或背景。

确认三视图后，后续可用其作为 `idle`、`thinking`、`working`、`thinking-working`、`waiting`、`success`、`error` 和 `disconnected` 动作帧的共同参考源。
