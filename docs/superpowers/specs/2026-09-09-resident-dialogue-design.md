# 常驻极简对话

右键菜单新增本次运行有效的「对话框常驻」开关，默认关闭。开启立即显示对话窗口；双击已显示的桌宠聚焦输入框。取消勾选恢复完整 IM 列表、关闭按钮和普通尺寸。

极简窗口使用半透明背景，不显示标题、发送或附件按钮。收起时隐藏整个回复区及其布局行，仅显示输入框，窗口按输入内容自动调整高度；附件标签、发送状态和权限确认按需显示。顶部横线可点击展开最近一条助手回复或收起，保持窗口底边位置并修正屏幕边界。展开 520 DIP，最大 560 DIP 且受工作区限制。滚轮在文本和 Markdown 内均滚动外层回复区。最近回复只是 UI 投影，不删除内存中的完整受限历史。

Enter 发送，Shift+Enter 换行，Esc 请求取消。输入框粘贴事件接受 BitmapSource，先限制 3200 万像素，再在内存编码 PNG，复用 2 MB/张、4 个附件和 DSH 图片上传链路；保留文本粘贴。失败只显示固定本地状态，不记录剪贴板内容。无协议、网络或会话持久化变更；保存布局时保留普通窗口高度。

验证：WPF STA 测试覆盖模式投影/恢复、展开上限、滚轮、权限与输入可见性、真实粘贴路由、图片数量/大小限制及普通文本粘贴；全量 Node、C#、自包含 Helper 构建和包测试。
