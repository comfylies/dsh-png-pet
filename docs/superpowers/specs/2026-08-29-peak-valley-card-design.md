# 桌宠左键峰谷卡片设计

## 目标

人物窗口左键短按显示一个短暂的 DeepSeek 峰谷状态卡片。它只提示当前计费时段，不读取账户、API Key、用量或对话内容，也不访问网络。原有双击人物打开对话窗口的入口保留。

## 规则

时间统一按北京时间（`Asia/Shanghai`）判定，避免依赖用户电脑的时区设置。

| 日期 | 高峰（显示“梁文峰”） | 空闲 / 谷时（显示“梁文谷”） |
| --- | --- | --- |
| 周一至周五 | 09:00–12:00、14:00–18:00 | 其余时间 |
| 周六、周日 | 无 | 全天 |

时段表集中在一个纯本地的 `PeakValleySchedule` 中。产品规则更新时只改此表和对应单元测试；卡片与鼠标逻辑不包含任何时间段常量。

> 依据用户提供的 DeepSeek 开放平台公告：自北京时间 2026-08-23（周日）00:00 起，周六、周日全天不再区分峰谷时段，统一按低谷价格计费。实现将此规则集中在 `PeakValleySchedule`，便于后续公告变更时单点更新。

## 左键与生命周期

- 左键短按并释放：计算当前时段，显示或刷新峰谷卡片。
- 卡片显示满 5 秒自动关闭。
- 5 秒内再次左键：重新计算状态并从头开始计时，不叠加多个卡片。
- 右上角 `×`：立即关闭并取消自动关闭计时器。
- 卡片已自动关闭或被关闭后，下次左键重新创建/显示。
- 按住并移动超过 Windows 系统拖拽阈值：沿用人物拖拽，不显示卡片。
- 双击人物：保留打开/聚焦对话窗口；第二击取消本次卡片显示，避免卡片与对话窗口同时抢占注意力。

拖拽阈值仍使用 `SystemParameters.MinimumHorizontalDragDistance` 和 `SystemParameters.MinimumVerticalDragDistance`。卡片显示、关闭和重置计时均在 WPF UI 线程执行；窗口关闭、隐藏到托盘或 Helper 退出时必须停止计时器，避免回调访问已销毁的窗口。

## 视觉与布局

卡片复用 `DialogueWindow` 的视觉语言：白色半透明表面、圆角、轻阴影与简洁浅色边框，但它不是可输入、可调整尺寸的对话窗口。

- 尺寸：高:宽 = `1:2`；高度按当前桌宠缩放后的头部高度计算，宽度为高度两倍。
- 位置：优先置于桌宠右侧，卡片垂直中心对齐桌宠头部；右侧空间不足时改置左侧，并完整钳制在当前工作区内。
- 层级：`Topmost`，不出现在任务栏，不抢占键盘焦点；关闭按钮可点击。
- 主文案：水平、垂直居中，大字号，第一版不显示金额、倒计时或模型名称。
- 高峰：`梁文峰`，红色（建议 `#D92D20`）。
- 谷时：`梁文谷`，绿色（建议 `#039855`）。
- 关闭按钮：右上角最小化 `×`，保留可点击面积和无障碍名称“关闭峰谷提示”。

主文案优先采用 **ZCOOL KuaiLe（站酷快乐体）**，其以 SIL Open Font License 1.1 发布，适合大字号中文卡通标题。实现时将字体文件与许可证一同随包分发；若加载失败，使用 Windows 已安装的 `Microsoft YaHei UI` 粗体回退。不得使用来源、许可或再分发条件不明的网络字体。

## 组件边界

新增独立的 `PeakValleyCardWindow`，负责显示、关闭按钮和 5 秒计时。`MainWindow` 只负责：识别左键短按、请求当前状态、确定相对位置、转发显示/关闭，以及在自身生命周期结束时释放卡片。

`PeakValleySchedule` 只接受一个可注入的当前北京时间，返回 `Peak` 或 `Valley`，不引用 WPF、文件、网络或 Harness。这样可稳定测试工作日高峰、工作日谷时、周末全天谷时及边界时刻（12:00、14:00、18:00）。

## 验收

- 周一 09:00–12:00、14:00–18:00 显示红色“大字梁文峰”；其余工作日时间显示绿色“大字梁文谷”。
- 周六日任何时间均显示绿色“大字梁文谷”。
- 卡片在 5 秒后消失，`×` 可立即关闭，重复左键会重置 5 秒倒计时。
- 右侧有空间时卡片显示在右侧；无空间时显示在左侧，始终完整可见。
- 拖动人物不触发卡片；双击仍只打开/聚焦对话窗口。
- 未读取或持久化 API Key、会话内容、用量和文件路径。
