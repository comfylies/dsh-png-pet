# 桌宠双窗口 UI 重构设计

## 目标

将桌宠改为双独立窗口：人物窗口（状态+形象）与对话窗口（输入+输出）分离，二者不绑定、可单独拖动；对话窗口采用白色半透明背景、可调大小、窄滚动条；同时修复"工作状态消失"与"输出栏关不掉"两个既有缺陷。

## 用户可见行为

### 人物窗口（MainWindow 重构）

- 220 基准尺寸，缩放档位 75%/100%/125%/150%（沿用现有）。
- 内容：鲸鱼形象 + 状态气泡（思考中/工作中/等待/已完成等）。
- **状态气泡不再被任何对话 UI 隐藏**（修复"工作状态消失"）：可见性只由桌宠状态决定（`idle` 隐藏，其余显示）。
- **左键拖动人物 → 对话窗口跟随移动**（两者相对位置保持不变）。
- **双击人物 → 切换对话窗口显示/隐藏**（打开时输入框自动聚焦）。
- 人物窗口上方保留空隙（鲸鱼图像上方透明区）作为拖动区；右键菜单与托盘行为不变。

### 对话窗口（新 DialogueWindow）

- **白色半透明背景**（`#F0FFFFFF` 级别）、圆角、`WindowStyle=None`、`AllowsTransparency=True`、`Topmost=True`、`ShowInTaskbar=False`。
- **可调整大小**（`ResizeMode=CanResize`）：边框/角落拖动，参考 Windows 标准窗口交互；最小 220×240。
- 布局（自上而下）：
  1. 顶部拖动/标题区（留空隙）："历史"按钮、标题、右上角关闭按钮（仅按钮关闭）。
  2. 输入区：文本框（Enter 发送、Shift+Enter 换行）、发送按钮、发送状态文本（已发送/已排队/未能发送等）。
  3. 输出区：最后回复（"正在生成回复…"占位 → 完整回复，可滚动，窄滚动条）。
- **输入与输出合并为一个窗口**：双击人物打开时两者一同出现，点关闭按钮一同关闭（修复"输出栏关不掉"）。
- 历史面板：点击"历史"后全窗口覆盖层（标题 + 关闭 + 最近 20 条消息列表，用户右对齐/助手左对齐）。
- **拖动**：Ctrl+左键 或 左键按住拖动移动窗口（单独移动，人物窗口不动）。
- **位置与尺寸记忆**：关闭时保存，重启后恢复；与人物窗口位置分开存储。

### 滚动条样式

- 宽度缩小（约 4px）、去掉上下箭头（自定义 `ScrollBar` Style，作用于输出区与历史列表）。

## 架构

### 窗口与组件

| 组件 | 责任 |
| --- | --- |
| `MainWindow`（重构） | 人物形象、状态气泡、拖动（联动对话窗口）、双击切换对话窗口、右键菜单、托盘 |
| `DialogueWindow`（新建） | 输入+输出合并栏、历史面板、关闭按钮、Ctrl/左键拖动、调整大小、位置记忆 |
| `DialogueWindowState`（新建） | 对话窗口位置+尺寸持久化（LocalApplicationData，独立于人物位置） |
| `ConversationState`（保留） | 协议状态机（回复/历史/发送状态），由 DialogueWindow 持有 |
| `App`（更新） | 双窗口生命周期、`InputSubmitted`/`HistoryRequested` 事件转发 |
| `PetTrayIcon`（保留） | 托盘：显示人物、退出 |

### 交互联动

- 人物窗口 `LocationChanged` → 对话窗口位置 = 人物位置 + 相对偏移（仅当对话窗口可见时）。
- 对话窗口移动（拖动）→ 只更新对话窗口位置与相对偏移。
- 双击人物 → 对话窗口 `Show()`/`Hide()`（不销毁，保留状态）。
- 对话窗口关闭按钮 → `Hide()`（隐藏而非退出进程；进程随 DSH 生命周期）。

### 协议

- JSON Lines v5 不变；`input`/`request-history` 由对话窗口发出，`reply`/`conversation-history`/`input-status` 等由对话窗口消费；`state`/`config` 由人物窗口消费。

### 状态修复

- 删除 `UpdateStateBubbleVisibility` 中的输入/输出/历史互斥逻辑：状态气泡仅按 `lastDisplayState.State` 显示。
- 对话窗口内输入框与输出区无互斥（同窗口同显同隐）。

## 错误处理

- 对话窗口状态文件损坏 → 默认位置（人物窗口右侧偏移 40px）与默认尺寸。
- 对话窗口拖动/调整大小失败不阻塞发送与历史。
- 双击与单击拖动冲突：`MouseLeftButtonDown` 的 `ClickCount == 2` 判定双击，单击启动拖动；拖动期间不触发双击。

## 测试

- C#：`DialogueWindowState` 存取/损坏回退；`ConversationState` 现有测试保留。
- Node 布局静态断言：DialogueWindow 存在（白色半透明、CanResize、窄滚动条样式、无箭头）、MainWindow 移除对话气泡、状态气泡互斥逻辑移除。
- 协议测试不变（v5）。
- 发布握手测试不变。

## 发布

- 版本 0.1.22（插件 + Helper 同步，含新构建 exe）。

## 非目标

- 不改协议消息与对话数据流。
- 不实现对话窗口与人物窗口的吸附/对齐动画。
- 不改变发送链路与历史提取逻辑。
