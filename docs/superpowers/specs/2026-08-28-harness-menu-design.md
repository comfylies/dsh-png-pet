# DSH Harness「桌宠」菜单设计

## 目标

将 DSH Harness Web 中的插件设置入口作为桌宠的**默认配置菜单**。它负责用户在启动桌宠前或使用期间设定默认会话、回复显示和默认外观偏好；桌宠窗口的右键菜单另有会话切换和宠物大小等即时自定义入口，本设计不定义其内容或样式。

菜单必须让用户一眼回答三个问题：桌宠默认把消息发到哪里、会显示多少回复、默认以什么大小和动态效果启动。所有修改自动保存，无需单独的“保存”按钮。

## 信息架构

Harness 设置页注册一个顶级条目：`桌宠`。进入后按下列顺序显示三个卡片式分组：

1. **会话**：决定桌宠输入的目标 DSH 会话。
2. **回复显示**：决定是否及以多长的范围显示本次桌宠输入关联的回复。
3. **外观与动效**：决定桌宠的默认大小和是否减少动画；这两个值保存到 DSH 设置，供下次 Helper 启动时恢复。

不加入模型选择、API Key、工作目录、提示词、工具参数、会话正文、历史记录或调试日志。这些信息不属于桌宠配置，也不应在该菜单中读取或显示。

## 交互细节

### 会话

- **默认会话**使用 Harness 已提供的本机会话列表。下拉项只显示经过 Harness 投影的会话标题；内部 ID 仅作为控件值写入设置，绝不显示或记录。
- 第一项固定为“未选择”。选中它会清除默认会话；桌宠仍可打开，但发送区显示“请在 DSH 设置中选择会话”。
- 会话列表加载时选择器禁用，并显示“正在加载会话…”。列表不可用时显示固定错误“会话列表尚未就绪。”，不显示原始异常。
- 已保存的会话不再存在时，选择器显示“所选会话已不可用。”和“重新选择”提示；Host 按既有逻辑清除失效配置。不会自动猜测或切换到“最近会话”，以避免误投递。

### 回复显示

- **显示回复预览**默认关闭。打开后，桌宠仅显示用户从桌宠发送的那一次请求所关联的助手可见文本；不显示其它会话轮次、思维链、工具内容或历史记录。
- 开关关闭时，**预览长度**置灰并保留已保存数值；重新打开时恢复该数值。这样可以避免一个无意义的长度输入，也不丢失用户偏好。
- 长度使用带数值输出的范围输入：范围 `80–2000`，步长 `20`，默认 `480`；屏幕阅读器以“预览长度，480 个字符”读出。实现仍接受任意 `80–2000` 的整数，避免破坏既有设置或 API。
- 每次变更立即写入设置。写入期间控件保留用户选择并显示轻量“正在保存”；失败时恢复最后一次已确认值，并在该卡片内显示“无法保存桌宠设置。”

### 外观与动效

- **默认宠物大小**采用互斥的单选组：75%、100%、125%、150%，默认 100%。它定义 Helper 启动时及用户选择“恢复默认”后的尺寸；切换后立即向已运行的 Helper 下发已确认设置，下次启动也使用该值。
- **减少动态效果**默认关闭。打开后 Helper 固定显示当前动作的首帧；关闭后恢复动作播放。该项不影响状态气泡文字和桌宠输入/回复功能。
- 这两个项目应迁移为 `DialogueSettings` 同一 scope 内的持久化字段（建议命名 `scale` 与 `reducedMotion`），取代仅保存在 Helper 本地状态中的偏好。Harness 为事实来源；设置 watcher 负责把已提交值广播给 Helper。

## 状态、保存与一致性

- 菜单中的值以 Harness settings scope 的最新已提交快照为准。用户操作可以乐观呈现，但收到更新失败或冲突后必须回滚到该快照。
- 页面初始加载期间用骨架/禁用控件表示，不使用默认值覆盖尚未到达的真实设置。
- Helper 未连接、已隐藏或刚重启不使页面不可编辑。保存成功后，运行中的 Helper 收到更新；未运行时，新配置在下次启动生效。
- 右键菜单中的会话切换和大小自定义属于当前桌宠的直接操作。Harness 页面始终展示已保存的**默认值**，不会把右键菜单的临时自定义误显示为新的默认值；若右键操作需要写回默认值，必须通过与本页面相同的 settings scope 提交，提交成功后才刷新页面。
- 若 Helper 拒绝无效载荷或断连，Harness 只显示“桌宠暂未连接”；不得将 stdin/stdout 原文或运行时异常暴露到菜单或浏览器控制台。

## 数据与隐私边界

```text
Harness 设置页
  ├─ 本机会话列表：标题用于渲染，ID 仅写入 settings scope
  └─ 桌宠设置：defaultSessionId / previewEnabled / previewMaxChars /
                scale / reducedMotion
                 │
                 ├─ Host：用 defaultSessionId 投递 DSH follow-up
                 └─ JSON Lines：下发 previewEnabled、previewMaxChars、scale、
                                 reducedMotion，以及右键菜单按需使用的短暂 menu-config
```

`defaultSessionId` 是 Harness 的已保存默认值。为支持右键菜单的会话切换，Host 可在一次短暂的 `menu-config` 中向 Helper 下发当前可选会话的内部 ID 与标题，但 ID 只可作为回传动作的非显示值：不得写入日志、文件或设置以外的持久化介质，也不得被 Helper 作为界面文案展示。回复文本只按现有用户授权的、关联本次请求的短暂 JSON Lines 例外传递，绝不写进 DSH 设置、位置文件或日志。

## 实施边界

本设计只涉及 Harness Web 的“桌宠”设置菜单及其设置同步；不改变右键菜单、托盘菜单、会话创建/删除、对话历史、模型设置或网络边界。

落地时，`conversation-config` 应把当前默认会话投影为 `hasDefaultSession`，用于输入可用性；右键菜单所需的会话列表另走严格的短暂 `menu-config`/`menu-action` 协议。`config` 消息扩展后的默认 `scale` 与 `reducedMotion` 继续保持固定枚举/布尔校验。任何协议字段变更都须同步 TypeScript、C# 与测试，并升级协议版本。

## 验收标准

- 用户能在 Harness 的“设置 / 桌宠”中完成默认会话、预览和默认外观配置，而右键菜单仍可独立提供即时自定义。
- 会话标题以外的会话数据不被渲染；如为右键切换临时下发会话 ID，该 ID 不显示、不记录且仅能用于受限回传动作。
- 预览关闭时，长度控件不可编辑且不丢失值；任何回复内容、历史或工具内容均不在设置页出现。
- 默认宠物大小和减少动态效果在 Helper 重启后仍保留，并在运行中即时生效；右键菜单的临时大小不覆盖 Harness 默认大小。
- 加载、会话失效、保存失败和 Helper 断连均展示固定、可理解的提示，不泄露原始错误或敏感数据。
