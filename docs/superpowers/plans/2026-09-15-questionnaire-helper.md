# 问卷 Helper 接入实施计划

本轮接通已有分阶段行为：`pet` 在桌宠填写；`both` 保持原生 Web 问卷可回答，桌宠只读同步；`web` 不显示问卷卡。真正双端抢答需要可撤销 Web 等待的正式接口，本轮不声称完成。

1. 先补 Host 测试：原题/选项不能截断；原生 ID 仅在 Host 映射；非法、漏题、重复、过期答案拒绝；预先取消、超时、窗口关闭、切换会话清理；双端模式不吞掉 Web waterfall。
2. 协议升级 v18，新增 `answerable` 和显式取消；TS/C# 严格校验嵌套字段、重复标识、长度和类型，拒绝 v17。
3. WPF 新增分页问卷卡，单选/多选/其他文本，保留当前批次草稿，末页校验后提交一次，显示提交等待、完成/取消状态。所有内容只存内存。
4. App 解析分派、序列化答复/取消/打开 DSH；窗口关闭、Host 结束、会话切换清理请求。
5. 完整 Node/C# 测试、WPF 布局渲染检查、自包含 Helper 构建和打包验证。不安装到正在运行的 DSH。

安全投影仅取 `user-questions/request` 正式 UI 字段，不读取 `tool/call` 参数。超限题目、带 `detail`/`intent` 的审阅题、带扩展选项说明的题目回退原生 Web，避免截断影响用户决定。
