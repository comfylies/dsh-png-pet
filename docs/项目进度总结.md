# DSH PNG 桌宠项目进度总结

更新时间：2026-08-25

## 已完成

- [x] Windows-only DSH 插件包 dsh-png-pet，可安装到 DSH web profile。
- [x] TypeScript 插件启动、握手和有序关闭 C# WPF Helper。
- [x] .NET 10 Windows x64 自包含单文件 pet-helper.exe，随 npm 包发布。
- [x] stdin/stdout JSON Lines 最小协议：ready、hello、config、state、shutdown、closed。
- [x] 透明、无边框、置顶、不出现在任务栏的桌宠窗口。
- [x] 左键拖动、窗口位置保存与恢复、75%/100%/125%/150% 缩放、重置大小与位置。
- [x] 右键菜单：隐藏、缩放、重置、关闭。
- [x] 系统托盘：隐藏后的显示入口、双击恢复和退出。
- [x] 新的透明睡眠鲸主题形象；原图白底和文字已移除。
- [x] Node 协议/生命周期测试、C# 协议/窗口状态测试、发布 exe 握手测试。
- [x] 已安装 dsh-png-pet@0.1.1 到 C:\Users\root\.dsh\profiles\web。

## 已验证命令

~~~powershell
npm test
dotnet test pet-helper.Tests\PetHelper.Tests.csproj --no-restore
~~~
